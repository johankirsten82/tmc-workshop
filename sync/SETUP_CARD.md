# TMC standard setup card (the ONLY setup text Johan ever gets)
Send exactly these 5 steps, same words and order. Change only <APP> and <SHEET LINK>. Attach sync/Code.gs as a file in the same message.
Do on the laptop. One time, ~5 minutes.

1. Open the [TMC <APP> Sheet](<SHEET LINK>) → **Extensions** → **Apps Script**.
2. Delete what's in the box, paste everything from the attached file, tap **Save** 💾.
3. At the top pick **setupOnce** → **Run** → **Allow**.
4. **Deploy** → **New deployment** → **Web app**. "Execute as **Me**", "Who has access **Anyone**" → **Deploy**.
5. Copy the link that ends in **/exec** and send it to TMC Base.

Rules: only TMC Base sends this card to Johan (app bots never send setup steps). No extra steps, no screenshots requests. After the /exec link, Johan does nothing more.
